Privacy Policy

Extension: SI Content & Commerce Agent
Version: 0.1.0
Last updated: 2026-11-28

Summary: This extension does not collect, transmit, or sell any personal data. All processing happens locally in your browser. You control all endpoints and credentials.

Data We Access

  • Active tab content — only when you click "Audit this tab" (requires activeTab permission + user gesture). We read the DOM to extract title, meta description, canonical, H1, and JSON-LD for SEO auditing.
  • Your settings — stored locally via chrome.storage.local. Includes RSS feeds, product SKUs, API endpoints, and keys you configure. Never sent anywhere unless you explicitly trigger a sync/research action.
  • Host permissions — optional_host_permissions: [""] is requested only when you add a new research source or merchant endpoint. You approve each origin via Chrome's permission prompt.

Data We Send

  • When you run Sync Feeds, the extension fetches RSS feeds you configured and sends the content to your configured AI endpoint (if enabled) for enrichment.
  • When you run Research, the extension queries Google News RSS, Google Custom Search, DeepSeek, or your MCP endpoint — all using your API keys.
  • When you run Price Sync, the extension calls your configured Digikala/Torob MCP endpoints.
  • When you run Campaign Analysis, the CSV is processed locally — no data leaves your browser.

Data We Never Touch

  • No analytics, telemetry, or usage tracking.
  • No account creation, no login, no user identification.
  • No cookies, no localStorage (only chrome.storage.local for your settings).
  • No third-party scripts, no external fonts, no CDN resources.

Your Control

  • Export/Import settings — JSON file with all your config (except keys, which stay in storage).
  • Clear all data — Extension options page has a "Clear storage" button.
  • Revoke host permissions — Chrome's site settings let you remove any granted origin.
  • Uninstall — Removes all local data automatically.

Compliance

  • GDPR: No personal data processed; you are the data controller for any content you import.
  • CCPA: No sale of personal information.
  • Chrome Web Store: Single-purpose (content/commerce agent), minimal permissions, no remote code.
